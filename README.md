# Student Record System

A C program designed to manage student records, developed for Daffodil International University (DIU) lab coursework.

## Features
- Add new student records
- Display student information
- Search and update student details
- File persistence for storing records

## How to Run
1. Open `STUDENT RECORD SYSTEM.C` in Code::Blocks or Visual Studio Code.
2. Compile and run the program using a GCC compiler.
